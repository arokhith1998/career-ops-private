For AboutAmazon.com, the citation question runs across five query shapes.

A first-week audit looks like this. Score each LLM and AI Overview for whether AboutAmazon.com is the cited source on the queries the newsroom should already own. The pattern of which buckets are weak tells you where the editorial + schema + canonical work should land first.
Why this shape matters

The patterns of weakness tell you which discipline to prioritize. If LLMs miss policy + community + sustainability buckets, the fix is structured-data hygiene (FAQ + Q&A + NewsArticle schema, source-linked claims, canonical clarity) - not more content volume.
