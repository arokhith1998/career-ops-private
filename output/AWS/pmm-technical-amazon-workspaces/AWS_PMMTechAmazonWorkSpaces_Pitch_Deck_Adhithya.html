The problem, as I read it

Five WorkSpaces products, three well-funded incumbents, and one new category story to tell at the same time. That is a fragmentation risk, not just a content backlog.

What makes this hard right now

Persistent desktops, pooled desktops, application streaming and secure browsing each have their own buyer moment, but Citrix, Omnissa and Microsoft AVD all sell a simpler, single-product story against you.
"Agentic AI desktops" is a new category claim. Said the wrong way to a CISO, it reads as a buzzword before it reads as infrastructure.
IT decision-makers, security leaders and desktop admins each need a different proof point from the same underlying product.

Why I have already run this exact problem

At Sensata, I owned positioning for a new sensing-product line sold into OEM and distributor engineers who had entrenched incumbent suppliers, turning technical specs into one buyer-ready story across regions.
At Applied Materials today, I build the value-based pricing and market-sizing models that sit directly with Engineering, the same technical-depth work a CIO conversation demands.
I am also building PriceKeel, my own B2B SaaS product, which keeps me on the buyer side of exactly this kind of infrastructure purchase decision.
The through-line: translating fragmented technical capability into one story a skeptical technical buyer will defend to their own VP, the same work, different hardware.
