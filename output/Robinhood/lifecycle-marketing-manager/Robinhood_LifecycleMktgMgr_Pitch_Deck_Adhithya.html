Why this deck exists

A brokerage app with millions of funded accounts does not grow by mailing more people. It grows by triggering the right message at the right point in the customer journey.

What that actually requires

A CRM and marketing-automation layer that reacts to real behavior (a first trade, a lapsed deposit, an unused feature) instead of a static, calendar-driven send schedule.
Segmentation built on real usage signal, so retention spend goes to the account that is actually at risk instead of a blanket campaign.
Cross-functional fluency with product, data and design, since a lifecycle trigger is only as good as the event data feeding it.

What I have already built at that layer

Rebuilt the WordPress-to-Pardot lead flow at Plug Power end to end, sequencing nurture by engagement signal instead of a fixed schedule, cutting cost per lead 50%.
Ran retention for an 8-client, $15K-$90K/month portfolio at Pixis, replacing a shared template with segmented, proactive playbooks that cut churn 50%.
Built SQL and GA4 cohort logic at Sensata across 50K+ connected devices to flag high-intent behavior early enough to trigger the next message, lifting feature adoption 18%.
The through-line: retention at scale is a systems problem (data, triggers, segmentation), and I have already built that system three times over, in three different industries.

First 30 days

What the first month in the Lifecycle Marketing Manager seat at Robinhood would look like.

Week 1
Map the current lifecycle
Audit the existing journey stages, triggers and send logic end to end to find where messaging is still generic instead of signal-driven, the same audit that grounded the Pardot rebuild at Plug Power before a single email changed.
Why first: retention work built on assumptions instead of the actual event data is the fastest way to waste send volume.
Week 2-3
Ship the first triggered segment
Take the single highest-friction stage in the journey (an idle account, a lapsed deposit, an unused feature) and ship one segmented, triggered campaign against it, instrumented in GA4 the way the Sensata cohort logic was.
Why now: one working trigger that outperforms the blanket send it replaced earns the room to build the rest of the map.
Week 4
Turn the win into the reporting cadence
Use what the first segment proved to set the retention and engagement dashboard the team reviews weekly, the same OKR cadence built at every employer to date.
Why this fast: a lifecycle program only earns budget by showing the pattern before asking to scale it.
