## Description

6sense seeks a Staff Product Manager to own critical components of their Agent Platform, including orchestration, agent execution frameworks, tool integration, and developer enablement. This is a highly technical individual contributor role reporting to the Product Lead, AI Platform.

Key responsibilities:
- Define roadmap for core agent execution systems, workflow orchestration, and state management
- Build agent development frameworks, standards, and APIs for consistent deployment
- Design capability registration systems enabling self-service tool and workflow registration
- Create SDKs and platform abstractions to reduce complexity
- Drive agent reliability through observability, debugging, and failure handling standards
- Enable multi-agent workflows supporting planning and task coordination
- Partner with product and engineering teams on platform investments

Requirements:
- "8+ years in Product Management"
- Platform, infrastructure, or AI platform experience
- Technical products ownership with architectural complexity
- Deep understanding of agent architectures, function calling, tool orchestration, and state management
- Cross-functional leadership influencing engineers and executives
