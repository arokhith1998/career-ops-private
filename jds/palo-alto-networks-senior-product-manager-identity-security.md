## Description
Manages key features across PANW identity security products, including Cloud Identity Engine and User-ID, covering identification, authorization, authentication, and posture management across cloud and on-premise networks. Works with cross-functional engineering, field teams, and external customers on upgrade strategies, solution presentations, and feature adoption. Responsibilities: manage IAM feature set (Cloud Identity Engine, User-ID); oversee authorization (users/groups/devices/attributes across directories); oversee authentication (NTLM, RADIUS, Kerberos, LDAP, SAML, OIDC, FIDO2, Passkeys); manage identity security/risk posture across IdPs, endpoints, SaaS apps; handle secrets vault, JIT access, Zero Trust, non-human identities; present to internal/external audiences; partner with engineering on upgrade strategy.
