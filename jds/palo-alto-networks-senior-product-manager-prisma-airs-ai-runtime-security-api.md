Job Summary

As a Senior Product Manager for Prisma AIRS - AI Runtime Security API, you will join a world-class team to tackle complex security challenges. You will be instrumental in conceptualizing and building innovative, AI/ML-powered security solutions for private and public clouds, directly shaping the future of AI security and collaborating with internal teams to solve challenging problems.

Key Responsibilities
- Define and manage the product requirements backlog for AI-powered runtime security features, ensuring alignment with strategic goals.
- Collaborate proactively with engineering and DevOps teams to deliver cutting-edge cloud security solutions on a SaaS platform.
- Own the maintenance and development of integrations with public cloud providers and inference platforms.
- Drive the next generation of Prisma AIRS Runtime UX (API for agentic investigations, UI for configuration workflows)
- Assist in capacity planning and global region expansions for Prisma AIRS API
- Own the ETL pipelines of data flowing into and out of Prisma AIRS to drive detection efficacy

Qualifications

Required Qualifications
- BS/MS in Electrical Engineering or Computer Science, or equivalent military experience.
- Must be able to write and commit code to production codebases.
- 5-7+ years of product management experience, specifically with SaaS enterprise security products.
- Demonstrable domain experience in cybersecurity.
- Strong domain experience with public cloud AI technologies such as AWS bedrock, Azure Foundry, or Google Cloud Gemini Enterprise Agent Platform, and AI platforms like Claude and OpenAI.

Preferred Qualifications
- Domain knowledge of SIEM/SOAR tools, AI/ML technologies and agents, and/or the AI security space.
- Experience building agentic projects.
- Experience building user experiences for security analysts (both UI and APIs for agentic investigations).
- Experience managing products that process big data and prioritize exceptional UX design.
- Experience scaling enterprise products from 1 to 1000x.
- Experience triaging customer requests and shipping features rapidly to drive customer success.
- Experience making product decisions based on imperfect market data and ambiguous information.
