## Description
Glean seeks a PM to lead API, SDK, and MCP strategy for developers within customer and partner organizations. The role emphasizes owning public API/SDK design, end-to-end developer experience, hands-on coding, documentation review, support pattern analysis, and metric-driven success measurement. The PM will lock API contracts before engineering begins and maintain scope discipline.

- Define and defend success metrics like time-to-first-call and integration success rates
