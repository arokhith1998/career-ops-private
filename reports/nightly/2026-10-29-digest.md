### System note for the maintainers

`generate-pdf.mjs` falls back to a 0.6in page margin whenever the input HTML has no
`--page-margin` CSS custom property defined, even with `--format=letter` — and this
candidate's actual resume/cover-letter HTML templates never define that property, so
every pack is at latent risk of a silently-margined PDF that `check-resume-fit.mjs`
(which measures the HTML, not the rendered PDF) would not catch. Caught and worked
around on the Netic and Mintive packs this run by adding an explicit
`:root { --page-margin: 0; }` override and re-verifying PDF page geometry directly
(`pdfinfo`) against a known-good sibling pack. Worth fixing at the template level
(`templates/cv-template.html`) so future packs don't depend on each build remembering
this.
